> [!info] str
> is a group of characters consisting of ASCII symbols that can be indexed.

## Applicable Functions:
- `"".split(sep:str, maxsplit:int)`: splits a String at every occurrence of `sep` up to `maxsplit` times 
- `"".replace(old:str, new:str, count:int)`: replaces `old` with `new` a maximum of `count` times
- `"".join(iterable:iterable)`: joins elements of `iterable` together into a String where every element is separated by the original String
