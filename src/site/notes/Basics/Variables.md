In maths, there are Variables. In Python, and all other programming languages too, they are a vital part of every program.
To use a Variable, choose a variablename, add `=` and continue with any value you want. Try it yourself

> [!question] Task
> Define a variable, for example `number`, assign it an Integer and print your variable plus 1
> > [!check]-
> > ```Python
> > number = 5
> > print(number + 1)
> > ```
> > The result:
> > ```
> > $ python3 ./Python/variables.py
> > 6
> > ```
