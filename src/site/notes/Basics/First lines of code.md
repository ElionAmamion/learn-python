To actually create your first program, create a new file and call it `firstProgram.py`. Now open the file. To test everything works as intended, we will use [[Functions/print()\|print()]]. This will allow us to see the result of anything within the parentheses when launching the program. For now we will start with `"Hello world!"`.

> [!question] Task
> Create a print statement, that contains `"Hello World!"`
> > [!check]-
> > ```Python
> > print("Hello world!")
> > ```

Now we want to run this script. For this we'll need the path to the file which we can get by clicking on the file and pressing
- Windows: `Ctrl+Shift+C`
- Mac: `Ctrl+Alt+C`

- Ubuntu, Debian, Fedora: `Ctrl+C`
- Arch: `Ctrl+Alt+C`

Now we can simply write `python` or `python3` and paste the copied path at the end like this.

```
$ python3 ./Python/firstProgram.py
Hello World!
```

If everything worked, it should say `Hello World!` in the next line.
There you have it, your first program in python!
