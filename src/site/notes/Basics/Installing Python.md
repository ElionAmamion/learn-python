There are obviously a bunch of installation guides online already, so I will try to make this as easy to follow as I can.
If you are on Windows or a Mac, then [this](https://www.python.org/downloads/) is the official Python downloads site, here you will click the \<Download Python \[*Version*\]\> button. You have now downladed the download wizard.
If you are on *Windows* you just need to run the file and check the \<add Python \[*Version*\] to PATH\> button at the bottom of the window. Now click on \<INSTALL NOW\>, the rest it will do automatically, so you'll just have to wait for the download to finish.
On *Mac* it is quite similar,  but you'll have to accept a few things, like where it is downloading to, here you just have to click yourself through all the dialog and it will install itself with everything you'll need.
If you are on linux, it could either be already installed, which can be checked with either `python --version` or `python3 --version`,
or you'll have to open the terminal, in which the command can vary quite a bit depending on which distro you have, I've listed the most common ones below:

- Ubuntu: `sudo apt install python3 python3-pip`
- Debian: `sudo apt install python3`
- Fedora: `sudo dnf install python3`
- Arch: `sudo pacman -S python3`
